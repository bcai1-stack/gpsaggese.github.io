录制时由本人填写并口述姓名、UID、工具与难度；个人介绍不可由代码代替。

| 时间 | 演示内容 |

| 0:00–0:30 | 姓名、UID、MSML610、项目标题、PyTorch/CVXPYlayers、选择的难度 |
| 0:30–1:00 | 最终提交时展示 PR、Issue #760、项目目录和文件命名；准备阶段可先用本地项目演练 |

Python 实现和测试均在 Notebook 中，修改函数的位置是 `mvo_utils.ipynb`。演示时解释 `%run ./mvo_utils.ipynb` 如何加载保存后的函数，并在新内核中依次执行必要单元。Docker 启动脚本和文档各自保留原格式。
